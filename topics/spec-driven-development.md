# Spec-driven development

Resources on using structured, versioned specifications to guide AI-assisted software development from requirements through design, implementation, and validation.

## Spec-Driven Development: Designing Before You Code (Again)

- **Date added:** 2026-09-16
- **Source:** Dave Patten / Medium
- **Link:** https://medium.com/@dave-patten/spec-driven-development-designing-before-you-code-again-21023ac91180
- **Summary:** Explains how versioned specifications can turn AI coding from one-off prompting into an auditable spec-to-plan-to-implementation workflow, with human review and testing gates.

## Spec Kit

- **Date added:** 2026-09-16
- **Source:** GitHub
- **Link:** https://github.com/github/spec-kit
- **Summary:** An open-source toolkit and workflow for making specifications the primary project artifact before AI agents plan tasks and generate code.

## Spec-driven development with AI: Get started with a new open source toolkit

- **Date added:** 2026-09-16
- **Source:** GitHub Blog
- **Link:** https://github.blog/ai-and-ml/generative-ai/spec-driven-development-with-ai-get-started-with-a-new-open-source-toolkit/
- **Summary:** Introduces Spec Kit and shows how living specs provide coding agents with explicit intent, constraints, and a shared source of truth.

## Spec-Driven Development: A Spec-First Approach to AI-Native Engineering

- **Date added:** 2026-09-16
- **Source:** Microsoft for Developers
- **Link:** https://developer.microsoft.com/blog/spec-driven-development-ai-native-engineering/
- **Summary:** Describes a spec-first model that keeps stakeholder intent, requirements, architecture, implementation, and validation aligned as AI accelerates delivery.

## Understanding Spec-Driven-Development: Kiro, spec-kit, and Tessl

- **Date added:** 2026-09-16
- **Source:** Martin Fowler / Birgitta Böckeler
- **Link:** https://martinfowler.com/articles/exploring-gen-ai/sdd-3-tools.html
- **Summary:** Compares three SDD approaches and explains the emerging spectrum from specs as temporary scaffolding to specs as the primary, persistent source of truth.
