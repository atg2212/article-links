# Article Links

A public personal knowledge base of useful resources, with a short summary for each link.

## Index

| Date added | Title | Topic | Source | Summary | Link |
|---|---|---|---|---|---|
| YYYY-MM-DD | Resource title | Topic | Publication / creator | One or two sentences on what it covers and why it is useful. | [Open resource](https://example.com) |

_Remove the example row when adding the first resource._

## Topics

As the collection grows, group detailed notes into topic files under `topics/`, for example:

- `topics/ai.md`
- `topics/product.md`
- `topics/engineering.md`
- `topics/business.md`
- `topics/misc.md`

Keep this README as the main index. Add a topic file only when there are enough related links to make grouping useful.

## Entry format

Use this format in a topic file:

```markdown
## Resource title

- **Date added:** YYYY-MM-DD
- **Source:** Publication / creator
- **Link:** https://example.com
- **Summary:** A concise summary of the resource and its main ideas.
```
